# Map Features

For each approved Requirement, identify observable capabilities needed to
satisfy it. Allocate stable Feature IDs and create minimal metadata/skeletons,
not premature detailed design. Link parents in both directions. Record priority,
rigor A/B/C, gate relevance, dependencies/blockers, preliminary Art/Audio impact,
technical questions, and owning next role.

Detect orphan Requirements/Features, circular dependencies, hidden enabling work,
and scope that does not serve a Requirement. Produce an implementation-neutral
feature map; detailed behavior belongs to `$design-feature`.
