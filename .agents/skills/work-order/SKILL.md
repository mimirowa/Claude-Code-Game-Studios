# Work Order

Read Feature, Blueprint, testability findings, dependencies, contracts, budgets,
ADRs, and current code. Confirm readiness/blockers; do not manufacture missing
specification. Allocate `WO[-DOMAIN]-NNN-NN` and use the Work Order template.

Make scope small enough for one coherent implementation checkpoint. Specify exact
in/out scope, affected components, interfaces, constraints, required tests,
criteria, performance constraints, and Definition of Done. Link parents and
dependencies bidirectionally. Rigor C may begin from a clear Producer brief when
no non-trivial Blueprint is needed. Assign Implementer only when executable
without hidden chat context.
