# Design Feature

Act under Specialist Design contract. Read parent Requirements, Vision/Pillars,
research, dependencies, related Features, and known Tech constraints. Complete
the Feature template: value, intent, rules, scope/out-of-scope, interactions,
tuning intent, Art/Audio impact or N/A, technical questions, acceptance criteria,
risks, and open questions.

Criteria must describe observable PASS/FAIL behavior without prescribing code.
Request Tech feasibility where uncertain. Advance to `FEATURE_DESIGN`; rigor A
and appropriate B continue to Blueprint/Testability. If discovery invalidates the
Requirement, move backward and record why rather than patching around it.
