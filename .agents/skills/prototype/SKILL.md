# Hypothesis-Driven Prototype

Create `PRO-NNN` from the Prototype Findings template before code. Record the
question/hypothesis, why it matters, method, measurable success/failure criteria,
and time/compute budget. Put code under a configured prototype root and keep it
isolated from production imports/state.

Build only enough to test the hypothesis. Capture commands, environment, results,
measurements/screenshots as applicable, and limitations. Finish the artifact with
what was learned, decision/implication, and follow-up. Prototype code is
disposable and must be rewritten against a Blueprint/Work Order if promoted;
never let it silently accrete into production architecture.
