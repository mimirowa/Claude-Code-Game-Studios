# Gate Review

Allocate/update a Gate Review artifact. State the question, required evidence,
required Features, quality criteria, acceptable gaps, blockers, and decision
owner before assessing. Producer compiles canonical links; QA provides objective
results; Directors review triggered cross-domain quality; Executive Producer
approves the material gate decision.

Return `GO`, `CONDITIONAL_GO`, or `NO_GO` with evidence, conditions, owners, and
recheck date/criteria. A prototype is risk-retirement evidence, not a mandatory
quality gate. Validation passing does not authorize release/deployment.
