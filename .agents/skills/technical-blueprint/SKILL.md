# Technical Blueprint

Act under Specialist Tech contract. Read parent Feature/Requirement, current
architecture/ADRs, exact stack pins, configured budgets, research/prototypes, and
QA needs. Use the Blueprint template. Define architecture, state ownership,
interfaces/contracts, algorithms, persistence, observability, failure handling,
migration/security, tests, and measurable technical criteria.

Explicitly capture current/future multiplayer expectation, authority and
client/server seams, serializable commands/events/state, determinism, persistence,
and replay implications without prescribing or implementing multiplayer.
Preserve approved product behavior; return infeasibility to Design/Executive
Producer. Create ADRs only for significant choices with meaningful alternatives.
