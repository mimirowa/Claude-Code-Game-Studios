# Map Requirements

Read Vision, Pillars, strategy, constraints, research, and existing Requirements.
Identify product outcomes without implementation detail. Allocate stable IDs;
deduplicate overlaps; record audience, value, scope, constraints, measures,
assumptions, evidence, risks, and open questions using the Requirement template.

Map Requirement relationships and priority/rigor. Challenge requirements with no
clear value or success evidence. Update parent/child links bidirectionally. Route
uncertainty to Research/Prototype and material scope/product choices to the
Executive Producer.
