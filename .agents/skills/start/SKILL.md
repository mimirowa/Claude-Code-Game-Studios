# Start

Read `framework.yaml`, `AGENTS.md`, layout configuration, technical preferences,
and `project/production/project-state.md`. Inspect manifests and configured roots;
do not assume the repository is new or follows defaults.

Report only: current phase/gate/objective, active artifact/task/role, blockers,
stack status, and missing state needed for a reliable handoff. Then route:

- Empty/early idea → `$brainstorm`, `$product-vision`, or `$research`.
- Existing/imported project → `$project-stage`.
- Active project with state → `$project-status` or the active artifact workflow.
- Unconfigured stack → `$setup-stack` when a stack decision/setup is in scope.

Ask about future multiplayer expectation if canonical state does not capture it.
Do not create a lengthy onboarding ceremony or auto-invent product direction.
