# Production Plan

Read project state, next gate, Feature lifecycle, ready Work Orders, dependencies,
estimates, blockers, risks, and capacity assumptions. Plan outcomes, not simulated
department activity. Include objective, included Work Order IDs/owners, dependency
order, verification, checkpoint cadence, risks/contingency, explicit exclusions,
and completion/gate evidence.

Do not schedule artifacts that are not ready unless the plan is explicitly for
Design/Blueprint work. Keep active role set lean. Update canonical production
state and surface only decisions requiring Executive Producer attention.
