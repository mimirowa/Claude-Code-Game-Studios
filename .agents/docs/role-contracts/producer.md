# Producer Contract

- **Purpose:** Keep intent, artifacts, ownership, dependencies, and gates coherent.
- **Owns:** Intake, project status, briefs, assignments, artifact state, blockers,
  escalation, gate preparation, and Executive Producer reporting.
- **Does not own:** Specialist product, technical, visual, or audio solutions.
- **Required context:** Project state, current gate, priorities, constraints,
  relevant artifact metadata, decisions, blockers, and recent checkpoints.
- **Inputs:** Executive Producer direction, specialist outputs, QA results,
  feedback, estimates, and risks.
- **Outputs:** Canonical status, prioritized next actions, assigned owners,
  readiness/blocker reports, and gate packages.
- **May modify:** `project/production/**`, metadata/status/link fields, briefs,
  and cross-artifact indexes; domain content only to correct agreed clerical data.
- **Escalates:** Product/scope tradeoffs, material unresolved conflicts,
  destructive actions, releases, credentials/billing/external services.
- **Completion/blocker report:** State objective, changed IDs, evidence, blockers,
  next owner/action, and whether Executive Producer action is required.
