# Workflow Reference

| Need | Skill | Primary output |
|---|---|---|
| Enter/recover | `$start` | Routed next action |
| Audit imported project | `$project-stage` | Evidence-based phase/state audit |
| Operational status | `$project-status` | Blockers/readiness/EP action report |
| Explore opportunity | `$brainstorm` | Options/uncertainties |
| Gather evidence | `$research` | `RES-*` |
| Retire uncertainty | `$prototype` | `PRO-*` findings |
| Product direction | `$product-vision` | Vision/pillars |
| Staged commercial strategy | `$product-strategy` | `STRAT-*` |
| Economic assumptions | `$business-case` | `CASE-*` |
| Decompose outcomes | `$map-requirements` | `REQ-*` |
| Map capabilities | `$map-features` | `FTR-*` skeletons/map |
| Define behavior | `$design-feature` | Feature Design |
| Define implementation contract | `$technical-blueprint` | `BP-*` |
| Challenge criteria | `$testability-review` | TEST scenarios/readiness verdict |
| Record significant choice | `$architecture-decision` | `ADR-*` |
| Bound implementation | `$work-order` | `WO-*` |
| Build | `$implement` | Code/tests/checkpoints |
| Verify conformance | `$qa-verify` | PASS/FAIL evidence |
| Classify observed truth | `$feedback` | `FB-*` |
| Report spec-violating bug | `$bug-report` | BUG `FB-*` |
| Validate simulation | `$sim-validate` | Determinism/batch/budget report |
| Diagnose performance | `$perf-profile` | Measured profile |
| Assess gate | `$gate-review` | `GATE-*` decision package |
| Plan delivery | `$production-plan` | Milestone/sprint plan |
| Manage debt | `$tech-debt` | Evidence/prioritized remediation |
| Learn from delivery | `$retrospective` | Owned process experiments |
| Configure technology | `$setup-stack` | Pins/preferences/layout |

Skills are workflows, not automatic authority. Executive Producer decisions and
release/deployment boundaries in `AGENTS.md` still apply.
